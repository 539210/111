# 云端提取交接包

这是提示词和参考资料，不包含四本PDF、原页图、模型权重、虚拟环境或密钥，没有发起云端任务。

## 使用顺序

1. 将本包提供给目标云端Codex任务，复制“云端执行提示词.md”分隔线之后的完整提示词。
2. 另将原文件指纹清单中的四本PDF提供到该任务可访问的私有输入位置；E盘路径不会自动同步到云端。本包不能单独完成识别任务。
3. 如需应用勘误，另提供原目录里的勘误DOC。
4. 让云端先核对输入与算力、网络、存储及gpt-6.1-terra/low子代理能力，再执行样本和整书提取。

## 材料说明

- 云端执行提示词.md：完整执行要求与三个低思考Terra审核者分工。
- 原文件指纹清单.json：四本输入的页数、大小、SHA256。
- 16页样本定位清单.json：可由原书重建的样本位置。
- 参考材料：历史测试结果、独立审查与接手信息。
- 参考脚本：Windows历史代码，仅用于理解接口；必须适配云端路径与平台，不是可直接运行的整书流水线。
- 已知错误样本参考：机器原始识别片段，不是标准答案，也不是经过修正的最终结果。原图需从对应PDF重建。

历史接手报告的“仅16页、整书待定”说明旧阶段，不限制新云端任务提示词明确授权的整书工作。当前本地模型继续保留，未因制作交接包而清理。

审核必须真实调用指定模型。若云端不支持该模型或子代理，不能声称已安排Terra审核。审核会增加耗时和模型用量；原CPU推理速度不能直接外推总交付耗时。

本包含教辅提取片段，供本任务私有交接，不要自动提交到公开仓库。
