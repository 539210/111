# ConvoLab

一个介绍 LeNet-5 的交互式中文网页。使用原生 HTML、CSS、Canvas 和 JavaScript，无构建依赖。

## 启动

需要 Node.js 18 或更新版本。在仓库目录运行：

```sh
npm run dev
```

默认端口为 3000，可通过 `PORT` 环境变量调整。

## 功能

- Canvas 三维投影网络：拖拽旋转、缩放、自动旋转及层间分离
- 网络层选择及参数、尺寸说明
- 五种手写样本、可调速的前向传播动画
- 桌面和移动端布局

推理为预设样本的教学模拟，不加载训练权重。C5 与 F6 合并展示，输出使用现代全连接分类头，区别在输出层说明中标注。字体服务不可用时自动采用系统字体。
